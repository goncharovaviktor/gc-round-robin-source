# Changelog

## 2.2.0 — 2026-09-21

- Полностью автоматическая установка инфраструктуры Cloudflare с нуля.
- `database_id` удалён: отсутствие ID включает штатное automatic provisioning
  D1 вместо обращения к несуществующему нулевому UUID.
- Первый `wrangler deploy` создаёт и привязывает D1, Queue и Durable Object,
  после чего скрипт автоматически применяет D1 migrations.
- Добавлены три ограниченные попытки миграции с паузами 5 и 15 секунд.
- Добавлены четыре unit-теста порядка и отказоустойчивости установки.
- Инструкция больше не требует вручную создавать D1, Queue или bindings.

## 2.1.2 — 2026-09-21

- Установка больше не зависит от автоматической замены D1 ID в Deploy button.
- D1 и две Queue создаются заранее через Cloudflare Dashboard без терминала.
- Нулевой D1 UUID блокируется до миграции с понятным сообщением вместо ошибки
  Cloudflare API `7404`.

## 2.1.1 — 2026-09-21

- Исправлена первая сборка через Deploy to Cloudflare: build больше не требует
  реальный D1 ID до того, как Cloudflare автоматически создаст базу.
- Формат `database_id` по-прежнему проверяется; миграция и Wrangler остаются
  финальными предохранителями от Deploy без созданной D1.

## 2.1.0 — 2026-09-21

- Установка без терминала через публичный GitHub и Deploy to Cloudflare.
- Автоматическое создание ресурсов и применение D1 migrations при Deploy.
- Конфигурация менеджеров в `src/manager-config.js` с атомарной синхронизацией.
- Предохранитель `MANAGER_CONFIG_READY` и контроль версии/hash конфигурации.
- GitHub build блокирует Deploy при ошибке конфигурации или тестов.
- 20 unit- и 13 Cloudflare integration tests, включая 1 000 одновременных
  запросов.
- Экспоненциальный backoff outbox до 15 минут при недоступной Queue.
- Отдельный DLQ consumer сохраняет исчерпанные сообщения в D1 `dead_letters`.
- Расширенный `/health` проверяет D1, менеджеров, GetCourse и admin-secret.
- Локальный HTML-генератор секретов.

## 2.0.0 — 2026-09-21

- Перенос атомарного round-robin в SQLite Durable Object.
- Отдельный outbox с Alarm и резервным Cron раз в пять минут.
- Асинхронная запись GetCourse через Queue с `max_concurrency = 1`.
- Экспоненциальные повторы и Dead Letter Queue.
- D1-журнал, защищённые admin endpoints и маскирование email.
- Идемпотентная повторная доставка одного job.
- `repair`/`requeue` без сдвига счётчика.
- Независимые пулы для сегментов и параллельных процессов.
- Стартовая позиция для миграции с предыдущего распределителя.
- Порядковый `sequence_number` для аудита строгой очереди.
- Автоматическая очистка успешных заданий после настраиваемого срока.
